# Dashboard Layout Decision

- Stitch Dashboard is the visual/layout baseline.
- Preserve the existing system sidebar.
- Preserve existing Dashboard API/data/logic.
- Change Dashboard content/layout only.
- Header: Faculty of Environment and Resource Studies, Mahidol University / Executive Dashboard.
- Report title: รายงานผลสัมฤทธิ์และแบบประเมินความพึงพอใจ.
- Global filters: กิจกรรม, ช่วงเวลา, and conditional year/date controls, plus reset.
- Activity context includes activity image.
- KPI: participants, respondents, unanswered, response rate, average score.
- Analytics: overall assessment, general respondent information with selectable dimension + donut, score by question, score distribution, highlights, feedback, activity photos.
- No AI, no Quick Actions, no mismatch warning, no new sidebar.
- Do not force the entire Dashboard into 1440x900 or a single screen when data density makes that impractical. Natural vertical scrolling is acceptable; prioritize readability and complete information over clipping/hidden overflow.
