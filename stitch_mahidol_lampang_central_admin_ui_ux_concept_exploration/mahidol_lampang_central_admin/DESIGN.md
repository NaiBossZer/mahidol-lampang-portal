## Brand & Style

This design system embodies an authoritative, calm, and highly structured institutional control plane tailored for university executive operations, faculty administration, and regional campus oversight. The interface communicates administrative prestige, rigorous academic integrity, and operational clarity.

The visual style is **Corporate Modern with High-Density Information Architecture**. It pairs crisp administrative containment with structural slate neutrals, using regal institutional blues grounded by functional emerald success states. The user experience prioritizes scan-density, immediate auditability, zero visual gimmicks, and strict WCAG AAA contrast compliance across all functional surfaces.

Key emotional attributes:
- **Authoritative & Trustworthy:** Sturdy structural hierarchy, formal color balance, and crisp geometric precision.
- **Calm & Focused:** Low-glare administrative slate backdrops reduce cognitive fatigue during prolonged multi-panel workflows.
- **Intelligent Density:** Balanced tabular grids, rigorous micro-typography, and distinct metadata grouping engineered for high-throughput decision making.

## Colors

The palette establishes an unmistakable institutional hierarchy through dual-layered royal navies and distinct state accents:

- **Primary Canvas & Surfaces:**
  - Base Workspace: `#F8FAFC` (Slate 50)
  - Surface Panel / Card Background: `#FFFFFF` (Crisp White)
  - Muted Inset / Table Header Background: `#F1F5F9` (Slate 100)
  - Surface Hover / Row Focus: `#E2E8F0` (Slate 200)

- **Institutional Brand Accents:**
  - Primary (Deep Royal Navy): `#002D62` — used for key navigation rails, primary action buttons, authoritative badges, and formal identity headers.
  - Secondary (Mahidol Slate Navy): `#0F3664` — applied to sub-navigation, secondary headers, active state fills, and elevated indicators.
  - Tertiary / Accent (Emerald Green): `#15803D` (with `#2E7D32` for hovered states) — allocated for affirmative institutional approvals, active enrollments, budgetary surpluses, and system health status indicators.

- **Administrative Borders & Structural Rules:**
  - Perimeter / Card Borders: `#E2E8F0`
  - Subtle Dividing Rules / Grid Lines: `#F1F5F9`
  - Strong Border / Active Focus Ring: `#002D62`

- **Functional Status Indicators:**
  - Critical / Danger: `#DC2626` (Actions requiring administrative revocation, budget deficits, critical alerts)
  - Caution / Pending: `#D97706` (Awaiting provost review, draft state, prerequisite holds)
  - Information / System Notice: `#0284C7` (Informational broadcast, automated audit logs)

- **Typography & Content Hierarchy:**
  - Primary Typography: `#0F172A` (Slate 900) — high-contrast clarity for metrics, data points, and body copy.

  - Disabled / Placeholder: `#94A3B8` (Slate 400).

## Typography

The typography architecture uses **Inter** for all interface layers, metrics, system controls, and structural data. When deployed in production environments supporting bilingual university assets, Inter is paired alongside native Thai typographic rendering (e.g. Prompt) via CSS font-stack fallbacks (`font-family: 'Prompt', 'Inter', -apple-system, sans-serif`).

Key typographic rules:
- **Numerical & Tabular Regularity:** All metric displays, ledger tables, student ID blocks, and administrative counts must activate tabular figures (`font-feature-settings: "tnum" 1, "cv05" 1`) to ensure stable vertical alignment across dense rows.
- **Header Structure:** Headings are authoritative and restrained. Uppercase formatting is reserved solely for `label-sm` category identifiers, status pills, and table headers.
- **Vertical Rhythm:** Line heights adhere strictly to an 8px/4px scale ensuring zero baseline drift inside compact table viewports.

## Layout & Spacing

The layout is built upon a **12-column responsive fluid grid with fixed administrative framing**. 

- **Primary Framing:**
  - Executive Persistent Left Sidebar: Fixed width of `260px` (`68px` collapsed for dense analytical states).
  - Main Administrative Canvas: Fluid 12-column grid scaling up to a max container width of `1600px` on ultra-wide executive dashboards.
- **Breakpoints:**
  - Desktop / Executive Displays (`≥ 1280px`): Full 12-column grid, persistent multi-tier sidebar, persistent breadcrumb trail, and secondary inspection side-drawers. `gutter: 1.5rem`, `margin: 2rem`.
  - Compact Tablet / Workstation (`768px – 1279px`): 8-column layout, auto-collapsing sidebar to icon-rail mode, stackable filter ribbons. `gutter: 1rem`, `margin: 1.5rem`.
  - Field Inspection / Mobile (`< 768px`): 4-column layout, bottom-anchored modal drawers, single-column vertical stacking. `gutter: 0.75rem`, `margin: 1rem`.

- **Information Density Rhythm:**
  - Padding within data cells, toolbars, and filter trays defaults to `space-sm` (`8px`) and `space-md` (`12px`) to maximize immediate viewability of audit records without artificial scrolling.
  - Card inner padding uses `space-lg` (`20px`) for high-level summary cards, shrinking to `space-md` (`12px`) for nested sub-panels.

## Elevation & Depth

This design system prioritizes **Tonal Layering and Low-Contrast Outlines** over heavy shadows to establish a clear, glare-free, enterprise-grade surface stack:

- **Surface Level 0 (Base Canvas):** `#F8FAFC` — structural neutral backdrop, zero elevation.
- **Surface Level 1 (Card & Module Layer):** `#FFFFFF` bordered by a crisp `1px solid #E2E8F0`. Shadows are minimized to an ultra-diffuse ambient depth: `box-shadow: 0 1px 2px 0 rgba(15, 23, 42, 0.04)`.
- **Surface Level 2 (Floating Action Panels & Dropdowns):** `#FFFFFF` encased in `1px solid #CBD5E1` with `box-shadow: 0 4px 6px -1px rgba(15, 23, 42, 0.07), 0 2px 4px -2px rgba(15, 23, 42, 0.05)`.
- **Surface Level 3 (Modals, Confirmation Sheets, Drawer Overlays):** `#FFFFFF` with `box-shadow: 0 20px 25px -5px rgba(15, 23, 42, 0.12), 0 8px 10px -6px rgba(15, 23, 42, 0.08)`. Backdrops feature a solid 45% tint of `#002D62` combined with a subtle `2px` backdrop blur to retain institutional identity during focus interrupts.

## Shapes

The design system adopts a **Soft (`roundedness: 1`) geometric profile**. Institutional software requires disciplined, structure-first geometry:
- Standard interactive elements (inputs, standard buttons, tabs, table cells): `0.25rem` (4px).
- Enclosing containers (cards, data tables, modal dialogs): `0.5rem` (8px).
- Compact badges, tag indicators, and audit status pills: `0.25rem` (4px) or full circular pills `9999px` strictly when conveying binary state conditions (e.g., Active / Inactive).
- Zero organic or asymmetrical shapes are allowed. Sharp internal structural corners reinforce precision and software reliability.
